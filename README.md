# VIX

Streaming desktop app per Windows — interamente locale, nessun server esterno richiesto.

## Installazione

1. Scarica `VIX_x64-setup.exe` da [Releases](../../releases/latest)
2. Esegui l'installer (richiede solo WebView2, già presente su Windows 10/11)
3. L'app si aggiorna automaticamente — niente da scaricare di nuovo

## Aggiornamenti

VIX controlla `latest.json` in questo repo ad ogni avvio e installa gli update in automatico.
